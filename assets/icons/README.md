# 图标资源说明

此目录包含QuickTranslate扩展的图标文件。

## 文件说明

- `icon.svg` - SVG格式的图标源文件，可通过转换工具生成PNG格式
- `icon16.png` - 16x16像素图标
- `icon48.png` - 48x48像素图标
- `icon128.png` - 128x128像素图标

## 图标转换

可以使用以下在线工具将SVG转换为PNG：
- https://cloudconvert.com/svg-to-png
- https://convertio.co/zh/svg-png/

## 临时解决方案

在开发测试阶段，可以复制SVG文件作为PNG占位符使用。
